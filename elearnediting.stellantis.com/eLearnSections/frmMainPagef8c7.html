140 - Alfa 159   2.4 JTD 20V   THE TELEPHONE DOES NOT SWITCH TO PRIVATE MODE (WHEN THE BUTTON IS OPERATED)   N058   

When the SRC button is pressed during a conversation in hands-free mode, the switch to individual mode does not take place.

This table does not consider faults due to service provider or phone function malfunction

The following telephones are enabled to operate in hands-free/individual mode with the Bluetooth system and are supported by the system on the vehicle:

- Audiovox®: SMT 5600 (Orange™ C500)*

- Motorola®: V525*, V600*

- Nokia®: 6230, 6600†, 6820, 7610*

- Sony Ericsson®: k700i

* The system is not currently able to support a GPRS connection (General Packet Radio Services) when it is connected to this mobile phone.

† The system is not currently able to support call waiting when it is connected to this mobile phone.
