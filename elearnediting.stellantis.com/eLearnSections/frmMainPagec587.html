Removing ( Refitting )

Family 91337/42

On this type of connection, the terminal is not replaced, only the connector block; if the cause of the problem is the terminal, then the engine prewiring assembly must be replaced.

The ways for this connector may not all be used; the free ones should be closed using the caps in the kit.

1. Remove the protective tape. Work on the retaining clips (1a), then release the terminal lock (1b) and fold it over.



1. Using the tool (1a), release the terminal retaining tabs and extract them from the connector block (1b). Make a note of the ways to be closed later on in the new connector block using the replacement caps (1c).

Refitting ( Removing )

- Close the ways not used with the replacement caps.

- Fit the terminal in the connector block checking that the retaining tabs are secured.

- Fit the terminal lock and renew the protective tape removed previously.
