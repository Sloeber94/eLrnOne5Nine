The remote control is supplied by a CR2032 lithium battery (3 V, 220 mAh) and remote control operation is ensured between 2.6 and 3.6 V with a maximum current of 15 mA. At least 9000 activations lasting 1 s and 3000 activations lasting 5 s are guaranteed for two years.

The battery voltage is monitored to check the charge level: the threshold is set at 2.6 V ±0.06 V. If the receiver detects that the battery is flat, it is still possible to carry out a total of 100 operations.

Variable code resynchronization

Note that after replacing the battery, the remote control variable code must be resynchronised: this operation is carried out by pressing the locking button on the remote control key twice.

Note that if the remote control has been activated more than 255 times, variable code synchrony between the sending unit and the receiver will be lost (the receiver will no longer be able to identify a variable code message correctly). Synchrony should therefore be restored by pressing the locking button on the remote control unit key twice
