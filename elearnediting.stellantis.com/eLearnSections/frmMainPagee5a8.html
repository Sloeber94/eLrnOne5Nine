Removing ( Refitting )

- Open the boot lid.

1. Open the light cover (1a) releasing the retainer (1b).

2. Disconnect the electrical connection.

 

Description

 

Component

 

LEFT REAR LIGHT CLUSTER (MOVING SECTION ON BOOT LID)

 

   See F035 LEFT REAR LIGHT CLUSTER (MOVING SECTION ON BOOT LID)

 

RIGHT REAR LIGHT CLUSTER (MOVING SECTION ON BOOT LID)

 

   See F036 RIGHT REAR LIGHT CLUSTER (MOVING SECTION ON BOOT LID)

3. Undo the light retaining nuts.

4. Remove the light from the outside.
Refitting ( Removing )

- Check that the light is not damaged.

- Position the light in the housing.

- Tighten the nuts.

- Connect the electrical connection.

- Position the light cover and attach the retainer.

- Close the boot lid.

- Check that the inner rear light cluster lights are working.

APPLICABLE TO VERSIONS WITH: Station Wagon
