OPERATIONS AT THE DEALERSHIPS

We inform you that on the web page www.blueandme.netthe software version 7.0 is available on the page www.blueandme.net to update the Blue&Me, Blue&Me Nav and Blue&Me Map systems on vehicles equipped with Blue&Me control unit having a Lauberhorn software.

The software 7.0 CANNOT BE updated on cars with Blue&Me system and Convergence control unit. For the type of Blue&Me control unit installed on the car (Convergence or Lauberhorn), refer to the description of Blue&Me system types shown below.

With the new software version 7.0, the following main improvements were introduced:

  • increased compatibility with the most recent mobiles
  • increased reading capacity for drive over 32 Gb
  • improved operation with iPods and iPhones
  • improved displaying of texts in Turkish

Connecting to the page www.blueandme.net, in the section SUPPORT - DOWNLOAD, a free download for software version 7.0 and the relevant instructions for the updating are available.

For all details about the installation procedure, carefully read the instructions that are attached and can be downloaded at the bottom of this SN, for your prompt reference.

WARNINGS

  • The updating process is simple and fast, because Blue&Me systems can be easily updated through USB. Nevertheless, the instructions must be carefully complied with, otherwise if the update is made in a wrong way, the system might not work anymore.
  • Remember that once this update has been performed, the previous software version cannot be restored anymore.
  • Before starting any update, the Bluetooth of the mobiles previously paired and present in the vehicle must be switched off.
  • During software update, no buttons must be pressed on the steering wheel.
  • After the software update, you need to pair again all mobiles previously linked to the Blue&Me.
  • If the mobile shows some pairing problems after the update, switch it off and then on again, removing the mobile battery for a while.
  • During the first pairing immediately after the update, the Bluetooth connection could disconnect, as the Blue&Me tests different pairing protocols to find the best one for the type of mobile.

TYPE OF BLUE&ME SYSTEMS

The vehicles can be equipped with the following types of Blue&Me control units

  • Convergence (first generation Blue&Me)
  • Lauberhorn (second generation Blue&Me)

The vehicles are equipped with Lauberhorn control unit starting from the following chassis numbers:

  • MiTo from chassis no. 1146542
  • Giulietta from chassis no. 7046044
  • 159 from chassis no. 7280561

If in the instrument panel, under "SETTINGS"-> "ADVANCED OPTIONS", the item "IMAGE ID" is displayed, the control unit is a second generation one.

In addition, connecting to the page www.blueandme.net, in the section SUPPORT - DOWNLOAD you can perform a free download of the BlueMeConfigurator programme, to find out the model and generation of Blue&Me installed on the vehicle.
