Description

 

Connector

 

1

 

Clutch pedal switch

 

   See I031 CLUTCH PEDAL SWITCH

2. Disconnect the master cylinder push rod from the clutch pedal.

3. Undo the bolt fixing the clutch pedal to the pedal mounting.

4. Compress and release the return spring (4a) for the clutch pedal (4b) and remove it.
Refitting ( Removing )

- Place the clutch pedal in position and, at the same time, fit the return spring, then secure it to the pedal mounting support using the bolt.

- Connect the master cylinder push rod to the clutch pedal.

- Connect the electrical connection for the clutch pedal.
