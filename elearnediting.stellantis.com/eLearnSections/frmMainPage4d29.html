CLAIMED FAULT

Error USB 10 displayed on the instrument panel after software update attempt to release 5.5.

OPERATIONS AT THE DEALERSHIPS

DEALERSHIP BEHAVIOUR STANDARDS TOWARDS THE CUSTOMER

  • Once the customer's claimed fault is confirmed, reassure the Customer that it can be solved by updating the Blue&Me™system control unit.
  • After completing the operation, illustrate what has been done and ensure that the Customer is satisfied.

Service Solution

Once the customer's claimed fault is confirmed, check the control unit software release and update it, if required, according to the Operating Cycle below.

OPERATION CYCLE

Check whether updating is necessary

Check whether the software needs updating as follows:

  • Connect using the EXAMINER and, in the Control Unit Test environment, select the item Comfort in the Group menu (1 - Fig. 1) and then the item Marelli/Microsoft Convergence in the System menu (2 - Fig. 1).

Fig. 1



  • Check the control unit software release (1 - Fig. 2).

Fig. 2



If the control unit software release is one of the following versions:

- 6314 -7152 - 8132 - 9037 - 9216 - 0137 - 8137 - 8165 - 8182 - 8291 - 9023 - 8016 - 8106 - 8127 - 8345

check the availability of S.O.S service and update.

If the software release is not included in the versions above, DO NOT continue with the updating.

B - Equipment required for control unit software updating

Before updating the software, check that the following equipment is available:

  • Personal Computer with Windows© 2000 / Windows© XP / Windows© VISTA.
  • Internet connection to website.
  • USB memory stick with manufacturer's certification of compatibility with Windows© 2000 / Windows© XP / Windows© VISTA operating systems.

C - Software updating procedure

- Download the file:

  • Unzip the file into a suitable dedicated directory (e.g. c:\Blue&Me).
  • At the end of the operation, make sure that only the files illustrated in Fig. 7 are present.

Fig. 7



  • Arrange a USB memory stick, capacity at least 128 Mb, formatting it in FAT32 to cancel all previous data.

It is advisable to use USB memory sticks with capacity below 8 Gb.
  • Store on the USB memory stick, in the main directory (folder), all previously downloaded files, making sure they correspond. The updating is not performed is the files are only on the memory stick inside a directory.

Before starting the updating, turn the mobile phone off. During software update, no buttons must be pressed on the steering wheel.

The update time depends on the car and the USB memory model; as an average, it can vary from 5 to 15 minutes.
  • With vehicle stopped and ignition key turned to STOP, place the USB memory stick in the Blue&Me™ NAV port at the bottom of the central console.

Updating is not available for vehicles NOT fitted with USB mediaplayer port. Do not use the diagnosis USB port of the control unit.
  • Place the ignition key on MAR, without starting the car, switch the radio on, clearing all warning messages (e.g. door open) on the panel display by pressing the button "Mode" or "Menu" (depending on the car model).

Never take out the memory stick from the USB port before the software update procedure is completed successfully.

The memory stick remains inserted even if the information "RE-START…" or "INSTALLATION IN PROGRESS..." is displayed, followed by date and time; the radio starts to play again even for a few minutes.

  • The following message appears on the control panel display: “UPDATING” and the voice message “update started” will be heard. If this does not occur, place the key to STOP position and to MAR - ON again. During upgrade, the display shows some messages about the progress.
  • At the end of the updating, the instrument panel display shows the voice command "COMPLETE" and the voice command "upgrade completed, remove the USB memory stick”.
  • The Blue&Me™ NAV updating process is complete, turn the ignition key to STOP and remove the USB memory stick.
  • Restart the car with key in MAR position and wait for about 2 minutes.

If the update is not complete the message “USB xx error” will be displayed and the following voice message will be played: "An error has occurred during updating". In this case, repeat the procedure.

D - Check to be carried out at the end of the updating

  • Use Examiner to check if the control unit software release has been modified.
  • Press twice the button TEL on the steering wheel and check the relevant message on the instrument panel (it should be like NO PHONE CONNECTED).
  • Press the S.O.S. button and check whether the service is available as described in paragraph A. Check of S.O.S. service availability.

If S.O.S service is no longer available after reprogramming, reactivate it as follows.

S.O.S. SERVICE REACTIVATION

To reactivate S.O.S. service, proceed as follows:

  • Find out the NIP code of the Blue&Me control unit, using the Examiner
  • Note down the NIP code and the other data on the special form, that can be downloaded from this Service News
  • Send the form by fax to the number shown (+39 06 41864814)

  • Connection with phones already previously connected will automatically occur without intervention; for the first few connections immediately after the update the Bluetooth® connection could disconnect, as the Blue&Me NAV tests different connection protocols to find the best one for the type of phone.
