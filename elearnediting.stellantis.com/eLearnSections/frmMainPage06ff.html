140 - Alfa 159   2.4 JTD 20V   TILT SENSOR ALARM NOT WORKING   A033   

The signalling of the presence of problems when the alarm system is turned on (door(s) and/or boot lid open) is carried out by means of a warning beep.

The system automatically excludes the perimeter protection for the door(s) and/or boot lid not correctly closed.
 

 

 

Test results
 

1

  

CHECK USING DIAGNOSTIC EQUIPMENT

  

All OK

  

Problems encountered

  

Operation
 

 

Connect the Examiner diagnostic equipment and check, in the parameters ambient, that the status (open/closed) for the doors and the boot lid has been correctly received.

  

Move on to Step 4

  

Error in receiving the door(s) and boot lid status (open/closed).

  

Move on to Step 2
 

2

  

ELECTRICAL CIRCUIT CHECK

  

All OK

  

Problems encountered

  

Operation
 

 

Check the continuity/insulation of the connection between the body computer node and the door(s) and the boot lid.

  

Move on to Step 3

  

Electrical connection damaged.

  

Restore the continuity/insulation for the damaged electrical connection

 See E7015 ALARM - DESCRIPTION
 

3

  

ELECTRICAL COMPONENT OPERATION CHECK

  

All OK

  

Problems encountered

  

Operation
 

 

Disconnect the connector, body computer node side, and check for the presence of the door and boot lid status signal (open/closed)

 See E7015 ALARM - DESCRIPTION

  

Move on to Step 4

  

Door status signalling switch not working

  

Replace the damaged switch

 Op. 7005N20 FRONT SIDE DOOR LOCK MOTOR/CATCH ASSEMBLY, LEFT OR RIGHT - R.R WITH DOOR PANEL AND SUPPORT FRAME REMOVED
 

Switch signalling boot lid status not working

  

Replace the damaged switch

 Op. 7015B10 SINGLE TAILGATE LOCK - R+R OR REPAIR WITH PANEL/PROTECTION REMOVED
 

Switch signalling bonnet lid status not working

  

Replace the damaged switch
 

4

  

CHECK ON CORRECT OPERATION

  

All OK

  

Problems encountered

  

Operation
 

 

Check that the fault is no longer present.

  

End of diagnosis

  

The fault persists.

  

Replace the Body Computer Node

 Op. 5505A32 BODY COMPUTER - R.R
