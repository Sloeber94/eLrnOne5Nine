Injector

 

   See N070 INJECTOR

   Op. 1060F36 PIPES (ALL) FROM FUEL MANIFOLD TO INJECTORS - R.R.

1. Undo the injector bracket retaining nuts.

2. Remove the injectors (2a) complete with brackets using the tool (2b).

If new injector/s is/are fitted it is necessary to:

- determine the identification code stamped on the top surface;

- check, using an Examiner, that the new injector(s) is (are) recognised by the engine management control unit.

Start the removal, beginning with the injector for cylinder no. 1 and continue with the injectors for cylinders 2, 3 and 4.
