Description of diesel engine (2.4 jtdm 210 cv)

A brief description of the main innovative/important features of the "new" Diesel 2.4 JTDM 20v Multijet 210 CV engine (Fig. 1) compared with the 2.4 JTDM 20v 200 CV engine currently in use is given below for quick reference.

The new 210 CV Diesel engine (like the 200 CV version) is equipped with the second generation MULTIJET COMMON RAIL system with direct injection into the combustion chamber in the piston.

We also wish to point out that the MULTIJET system has multiple injection at high pressure (up to 1600 bar) with the value electronically controlled in an extremely flexible manner since it is not connected to the engine speed;

A new GARRET type variable geometry turbocharger (previously KKK) with new design compressor and turbine impellers takes care of the supercharging.

Fig. 1



The following are also used:

-an injection pump with larger bearings-a special intake manifold with a new swirl actuator-a dedicated engine control unit (dedicated hardware and software)-new dedicated drains with a new filter (DPF)-new injectors with the jet rotated 180° and different surface treatment
