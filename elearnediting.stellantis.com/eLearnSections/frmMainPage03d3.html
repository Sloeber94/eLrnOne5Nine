140 - Alfa 159   2.4 JTD 20V   MIL WARNING LIGHT FLASHING   K048   

The engine fault warning light flashes with the engine started

The warning light can flash in two different ways: with the engine started up and the vehicle stationary or with the vehicle driving.
 

1

  

FUEL RESERVE WARNING LIGHT CHECK

  

ALL OK

  

PROBLEMS ENCOUNTERED

  

ACTION
 

 

Check that the fuel reserve warning light is off

  

Move on to Step 2

  

Fuel reserve warning light on

  

Top up the fuel level so that it is not in the reserve zone and continue to Step 4
 

2

  

FUEL LEVEL CHECK

  

ALL OK

  

PROBLEMS ENCOUNTERED

  

ACTION
 

 

Check that the fuel level gauge is working properly

  

Move on to Step 3

  

Fuel level gauge not working

  

Proceed as instructed in the

See table K020 LEFT BRAKE PAD WEAR SENSOR (SWITCH)
 

3

  

CHECK USING DIAGNOSTIC EQUIPMENT

  

ALL OK

  

PROBLEMS ENCOUNTERED

  

ACTION
 

 

Connect the diagnostic instrument (Examiner or Examiner Plus) and check the absence of the Misfiring error

  

End of diagnosis

  

The "misfire" error is present

  

Proceed as instructed in the

See table Z053 MISFIRE ERROR
 

4

  

ERROR CANCELLING AND CHECK

  

ALL OK

  

PROBLEMS ENCOUNTERED

  

ACTION
 

 

Using the diagnostic equipment, cancel the errors in the control unit.

Road test the vehicle and check that the errror does not occur again

  

Move on to Step 5

  

The "misfire" error is present

  

Proceed as instructed in the

See table Z053

 

5

  

CHECK ON CORRECT OPERATION

  

ALL OK

  

PROBLEMS ENCOUNTERED

  

ACTION
 

 

Check that the fault is no longer present

  

End of diagnosis
