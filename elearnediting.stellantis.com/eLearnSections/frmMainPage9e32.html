OPERATIONS IN NETWORK

Network behaviour standards towards the Customer

-When this problem is reported and confirmed, reassure the Customer that it can be solved by reprogramming the Blue & Me system control unit.-After the operation show the customer what has been done and make sure they are satisfied.

Service Solution

If this problem is reported and confirmed, proceed with the updating using the dedicated software as described in the Operating Cycle below.

OPERATION CYCLE

Procedure for acquiring software for updating

In order to be able to update the software, the following equipment is required:

-Personal Computer with Windows© 2000 / Windows© XP / Windows© VISTA.-Internet connection to website.-USB memory stick with manufacturer''s certification of compatibility with Windows© 2000 / Windows© XP / Windows© VISTA operating systems.

The USB memory stick to be used for the update must NOT be the one that comes with the vehicle with the Blue&Me Nav™ (C3). The procedure for acquiring the software involves deleting all the files in the memory before loading the zip file required for the updating. The USB memory stick contains the files for the pre-loaded maps and thefore, if used, will be deleted.

Download the file:

   Navigation ES OK pw blue.zip

-Unzip the file using the password - blue - onto an empty USB memory stick.-At the end of the operation only the files illustrated in Fig. 1 should be on the memory stick:

Fig. 1



    1. Get into the vehicle

    2. Turn the ignition key to the ON position

    3. Switch on the radio

    4. Insert the USB memory stick in the connector

    5. The message "ACTUALIZACION EN CURSO” should appear on the panel

    6. The radio should say “ACTUALIZACION EN CURSO”

    7. Wait for 1 minute and 10 seconds

    8. The message "ACTUALIZACION USB TERMINADA should appear on the panel

    9. The radio should say “ACTUALIZACION USB TERMINADA”

    10. Wait for 30 seconds

    11. Turn the ignition key to the OFF position

    12. Turn the ignition key to the ON position

    13. Switch on the radio

    14. Wait for 1 minute

    15. Press the NAV button in the courtesy light

    16. You should hear the message "The driver should follow the rules ....." in Spanish.

    Remove the USB memory stick at the end of the operation.

    End of update.
