Noisy - Service Solution


FAULT COMPLAINED OF

Noise coming from the boot especially over unmade roads (cobblestones).

TECHNICAL CAUSE

Boot lid lock guard incorrect size.

OPERATIONS IN PRODUCTION

Correct size of boot lid lock guard guaranteed.

Network behaviour standards towards the Customer

When this problem is reported and confirmed, reassure the Customer that it can be solved by fitting a new boot lid lock guard.

After the operation show the Customer what has been done and make sure they are satisfied.

Service Solution

If this problem is reported/confirmed, eliminate it by following the instructions in the operating cycle below.

OPERATION CYCLE
