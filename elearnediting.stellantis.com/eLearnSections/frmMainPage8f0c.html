OPERATIONS IN PRODUCTION

A "secret" six figure code (e.g. 409237) has been introduced inside C510, C513, C514, C514R and C530 type gearboxes. This code is stamped inside the gearbox casing in the position shown by the arrows in Fig. 1.

OPERATIONS IN NETWORK

If any operation has to be carried out that involves dismantling the gearbox casing and repairs to the inside, it is absolutely vital to include the "secret" code on the Claim Form (SR) as follows:

-Use "eSIGI++" and key in the code in the "Secret Code" field.-If you are using another means (for example DCS), key in the code in the first six spaces in the "Fault Description" field.

If an operation has to be carried out to a gearbox in which the new code has not yet been entered, no code needs to be put on the Claim Form.

If the operation on the gearbox does not involve opening the gearbox casing (for example, repairs to the gearbox external controls, removing the 5th and/or 6th speed rear cover, etc.) then no code should be entered.
