CODE - DESCRIPTION CODE - FUNCTIONAL DESCRIPTION CODE - WIRING DIAGRAM CODE - COMPONENT LOCATION Print electrical function

FUNCTIONAL DESCRIPTION

The CODE unit inside the Body Computer M1 is supplied by the battery from the line for the maxifuse in B99 - pin 18 of connector F and by the line protected by fuse F39 - pin 17 of connector F; the ignition-controlled supply (INT) reaches pin 9, from connector F.

The line leaving pin 29 of connector B of M1 is the W serial line connected with the engine management control unit M10 through which the key recognition dialogue and exchange of codes in recovery mode takes place.

In the case of normal operation, this dialogue takes place via the CAN.

The Body Computer M1 is connected via the CAN line to the instrument panel E50 to manage the "CODE failure" warning light.

The TEG Reader H3 recognizes the insertion of a known TEG and sends information via the CAN - pins 3 and 8.

The same signal is sent in a redundant manner to the steering lock node M89, from pin 2, and the latter sends it, in turn, via the CAN, to the Body Computer M1 and to the other nodes involved.
