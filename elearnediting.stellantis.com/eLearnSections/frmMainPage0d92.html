140 - Alfa 159   2.4 JTD 20V   NO ACOUSTIC WARNING FOR HANDBRAKE APPLIED WITH VEHICLE MOVING   G010   

With the vehicle moving, if the handbrake is accidentally operated this is not indicated by the acoustic warning.

The instrument panel node acquires the handbrake switch status and vehicle speed signal from the network. If the handbrake is activated and the vehicle speed is above 4 km/h, an acoustic warning is issued.

This function can be enabled/disabled using the MODE +/- buttons in the control panel. Make sure that the function has not been disabled by mistake by the user
