Removing ( Refitting )

The 4x2 version is described below

    Op. 7055B80 UNDERBODY SIDE PROTECTION (ONE) LEFT OR RIGHT - R.R.

    Op. 7050A20 ONE-PIECE REAR SEAT CUSHION - R.R.

1. Undo bolts (1a) and remove access cover (1b) for the submerged pump assembly complete with level gauge control.

1. Disconnect the rear fuel return pipe, submerged pump side, complete with level gauge control.

1. Position a hydraulic jack equipped with the appropriate tool for supporting the fuel tank.

2. Undo front bolts (2a) securing fuel tank support belts (2b).

- Lower the fuel tank as far as necessary to gain access to the clip securing the fuel return pipe to the body.

1. Disconnect the quick coupling for the rear fuel supply pipe, front fuel return pipe side.

2. Remove rear fuel return pipe (2a), after releasing it from fastenings (2b).
Refitting ( Removing )

- Refit the rear fuel return pipe in its seat and secure.

- Connect the quick coupling for the rear fuel return pipe, front fuel return pipe side.

- Secure the rear fuel return pipe with the fastening band located beneath the fuel tank.

- Place the fuel tank in position and secure it by tightening the bolts to the recommended torque.
