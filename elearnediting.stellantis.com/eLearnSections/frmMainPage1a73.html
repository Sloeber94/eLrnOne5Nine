140 - Alfa 159   2.4 JTD 20V   CLOCK NOT WORKING   K015   

With the ignition on, the display either does not show the time or it is not correct.
 

1

  

INSTRUMENT PANEL FUNCTIONS CHECK

  

ALL OK

  

PROBLEMS ENCOUNTERED

  

ACTION
 

 

Check:

  • That the display shows the correct time

  • That it is possible to adjust the time

  • That the clock moves forward

  

Move on to Step 2

  

1. The time displayed is not correct

  

1. Adjust the time
 

2. It is not possible to adjust the time

  

2. Move on to Step 4
 

3. The clock stays still

  

3. Replace the instrument panel

 Op. 5560B10 CONTROL PANEL - R+R
 

4. The display/time is not clear

  

4. Move on to Step 2
 

2

  

CHECK USING DIAGNOSTIC EQUIPMENT

  

ALL OK

  

PROBLEMS ENCOUNTERED

  

ACTION
 

 

Connect the Examiner diagnostic equipment to the diagnostic socket.

Check that there are no faults in the instrument panel

  

Move on to Step 3

  

Presence of errors

  

Continue following the instructions for the diagnostic equipment
 

3

  

CHECK USING DIAGNOSTIC EQUIPMENT

  

ALL OK

  

PROBLEMS ENCOUNTERED

  

ACTION
 

 

Keeping the Examiner equipment connected to the diagnostic socket, check the operation of the display in active diagnosis.

  

End of diagnosis

  

Display defective

  

Replace the instrument panel

 Op. 5560B10 CONTROL PANEL - R+R
 

4

  

ELECTRICAL CIRCUIT CHECK

  

ALL OK

  

PROBLEMS ENCOUNTERED

  

ACTION
 

 

Check:

  • Connections between left lever on steering column switch unit and instrument panel

  • Control panel power supply

  • Control panel earth

 See E4010 INSTRUMENT PANEL

 

Move on to Step 5

  

Connections defective, earth or power supply defective

  

Restore the correct connections, if necessary, replace the wiring.
 

5

  

LEFT STEERING COLUMN SWITCH UNIT LEVER CHECK

  

ALL OK

  

PROBLEMS ENCOUNTERED

  

ACTION
 

 

Check that the left steering column switch unit lever is working properly

 See E4010 INSTRUMENT PANEL

 

Move on to Step 6

  

Lever defective

  

Replace the steering column switch unit assembly

Op. 5550A12

 

6

  

CHECK ON CORRECT OPERATION

  

ALL OK

  

PROBLEMS ENCOUNTERED

  

ACTION
 

 

Check that the fault is no longer present

  

End of diagnosis
