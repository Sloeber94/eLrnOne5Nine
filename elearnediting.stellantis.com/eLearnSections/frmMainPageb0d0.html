Refitting ( Removing )

Check that the body computer is not damaged.

At the bench, connect the junction unit to the body computer and attach the retainers.

If the body computer is being replaced, proceed as follows.

If the Body Computer is being replaced, an "identical copy of the Body Computer" must be obtained from the Parts Dept. as a V.O.R. order quoting the vehicle chassis number: this copy will contain all the default settings entered when the vehicle was new which are stored in the Parts Dept. database for the vehicle chassis number.

If the same body computer that was removed is being refitted on the vehicle, use the Examiner to check that the system has not picked up errors during the operation.
