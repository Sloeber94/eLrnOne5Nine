SMS reader installation - Network Information and Service Manual Update


OPERATIONS IN PRODUCTION

It should be pointed out that on all vehicles equipped with Blue&Me™ (opt. 4J3) it is possible to integrate this system with an SMS message reader; this application allows the Customer to listen to the incoming message automatically on their mobile phone via the vehicle audio system equipped with Bluetooth®.

INTRODUCTION

The SMS message reader integrated with Blue&Me™ through voice synthesis technology, allows incoming messages to be automatically read via the vehicle audio system on mobile phones with Bluetooth®, also interpreting any abbreviations (*) within the text message.

The SMS message reader functions are managed using the controls on the steering wheel or Blue&Me™ voice commands.

The Blue&Me™ SMS message reader allows the Customer to:

Be informed, via a warning message in the instrument panel multifunction display, of a new incoming SMS message on their mobile phone with Bluetooth ® indicating the number/name of the sender and the Blue&Me™ system will also suggest reading the message out for them.

- Manage the SMS messages received list on a mobile phone connected to the Blue&Me™ system.

- Reread SMS messages already received and memorized.

- Make a voice call, using the controls on the steering wheel or voice commands, to the sender of the SMS message received.

- Delete individual SMS messages or the entire list of SMS messages received using the controls on the steering wheel or voice commands.

(*) The Blue&Me™ system is also capable of recognizing and reading any abbreviations (for example, "TVB" will be read as "Ti voglio bene" - I love you) and interpreting the most frequently used symbols (e.g. :-) will be read as "Smile") in text messages.

Telephones that support the Blue&Me™ SMS Message Reading function

Blue&Me™ is compatible with most mobile phones that support Bluetooth® 1.1 and a 1.0 hands-free profile (refer to the Bluetooth® connection specifications in the mobile phone user manual).

The ALFA ROMEO official website (www.alfaromeo.it) contains a list of mobile phones that are compatible with the Blue&Me™ system. We wish to point out that because of the different possible software versions available on the market for the different models of mobile phones, some functions may not correspond exactly to the description in this Service News.

some mobile phones in the list may not support the transmission of interlinked SMS messages (with more than 160 characters). Therefore, refer to the user manual for the mobile phone.

OPERATIONS IN NETWORK

The SMS Rider application can be installed as described in the operating cycle below.

OPERATION CYCLE

Necessary equipment

Before installing the SMS reader application, the following equipment must be available:

-Personal Computer connected to the Internet-USBPen (minimum size 256 Mb) with manufacturer''s certification of compatibility with Windows© 2000 and Windows© XP Operating Systems (see specific paragraph).

ALFA ROMEO periodically releases updates for the SMS reader application on its website www.alfaromeo.it.

Procedure for installing SMS Reader application

1. Access the Blue&Me™ portal on the ALFA ROMEO official website (www.alfaromeo.it - Technical section) and download the zip file containing the SMS Reader application to be installed on the Blue&Me™ system.

2. Extract the contents of the zip file downloaded from the Blue&Me™ portal, it is advisable to extract the contents into a dedicated directory (e.g. c:\Blue&Me).

3. Copy the following files into the memory of a USBPen from the files extracted:

- install.inf

- SMS_Reader.ARM920.CAB

4. There will be two files in the USB memory:

- install.inf

- SMS_Reader.ARM920.CAB

5. Insert the USBPen memory into the vehicle Blue&Me™ USB port (oddments compartment, see Fig. 2).
