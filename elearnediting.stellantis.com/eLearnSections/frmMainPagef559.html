140 - Alfa 159   2.4 JTD 20V   DISPLAY DOES NOT SHOW HEADLAMP ALIGNMENT DATA   K104   

When the selector which controls the headlamp alignment is operated (with the dipped headlamps on) the information on the display does not change. If the headlamp alignment is not working

See table I080 HEADLAMP ALIGNMENT CORRECTOR NOT WORKING

  • connection between dashboard control unit and instrument panel
