Instructions for requesting the secret code if the card is mislaid


Cancels and replaces SN 55.06.10 of 26/03/2010 for the introduction of Continental devices.

General information

Where provided, the "CARD" containing the serial number and the operation enablement code for the component provided with the vehicle comes together with the vehicle documentation.

This code is also called secret code or anti-theft code.

Depending on the type of component and/or electrical system installed, the code may be requested the first time the vehicle is started or each time there is a break in the power supply or a component is replaced (e.g. after the battery is disconnected, a fuse blows, the Body Computer is replaced, etc.).

If needed, the secret code can be requested via the CSPS by entering a dedicated order, following the procedure indicated below.

Check on rightful ownership

When the Dealer is asked for a new secret code, he should verify the validity of the documentation about the vehicle ownership.

Components that can be decoded

The brands of the components/systems that can be decoded using this procedure follow: Bosch, Continental, Harman, Magneti Marelli and Siemens.

Components branded Bosch may also be called Bosch/Blaupunkt or just Blaupunkt.

Composition of Serial Numbers

To request the secret code for the component involved, the serial number, which is usually above or next to the actual component on an adhesive label or stamped on a metal plate, is required.

An example is given below for each brand, with the composition of the serial numbers and their position.

BOSCH

Example of the serial numbers: 815BP632862782872 (or 815CM9391C0736647) and 7 612 001 433

There are two serial numbers to enter.

For the first serial number the characters are 17: 3 numeric, 2 alphanumeric (BP or CM) and the twelve that remain are numeric, with the exception of the tenth, which may be alphanumeric.

There are ten characters for the second serial number.

For all serial numbers the first two characters (AR or LA) indicate the vehicle brand (Alfa Romeo or Lancia) on which the components/systems are fitted.

The serial numbers for the ICS, from the third to the twelfth characters, are numbers, the thirteenth is always "/" and the last two are numbers again.

The serial numbers of the navigator are alphanumerical from the third to the thirteenth.

SECRET CODE REQUEST

Make sure that you have the correct serial number, then carry out the following operations via the CSPS:

  • go to ORDER MANAGEMENT (A - Fig. 6) and select the SECRET CODE REQUEST (B) menu item; the screen shown in Fig. 6 will be displayed, now select the following in this order:

1 - Select ORDER TYPE

2 - Insert CUSTOMER DATA

3 - Insert MODEL AND CHASSIS

4 - Insert the equipment serial number

5 - Click on ENTER ORDER, the screen shown in Fig. 7 will be displayed

Fig. 6





Select the following in this order:

1 - Select the delivery address

2 - Insert part number and quantity. (no. 71734884 for Alfa models and Q.ty = 1)

3 - Click on SAVE and STAY, the screen shown in Fig. 8 will be displayed

Fig. 7





  • The order will be processed by the system and, after a few days, the secret code will be visible in the SECRET CODE field (1 - Fig. 8).
  • The card reporting this code will be delivered to the selected address.
