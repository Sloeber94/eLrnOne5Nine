Removing ( Refitting )

1. Open the tailgate and support it.

2. Using a screwdriver, release the retaining springs from both ends of the telescopic strut (without removing them).

3. Remove the telescopic strut.

4. Undo the ball pins, if necessary.
Refitting ( Removing )

- Check that the telescopic strut is not damaged.

- If removed, retighten the ball pins.
