140 - Alfa 159   2.4 JTD 20V   PRECONVERTER OUTPUT TEMPERATURE SENSOR OPERATION CHECK   1080BG   
 

STEP

  

CHECK TO BE PERFORMED

  

RESOLUTION IF THE CHECK IS NOT OK
 

1

  

Check whether error P2080 - Temperature sensor on preconverter output - is present using the diagnostic equipment

  

Replace the temperature sensor

   Op. 1080B64 CATALYTIC CONVERTER EXCESS TEMPERATURE THERMOCOUPLE - R + R
 

2

  

Press the START/STOP button and turn off the engine.

Disconnect the wiring harness connector from the upstream particulate filter temperature (DPF)

Press the START/STOP button.

Check that the voltage across pin 1 and 2 of the sensor

   See K189 UPSTREAM PARTICULATE FILTER TEMPERATURE SENSOR (DPF)

is greater than 4.8 V.

Move on to Step 4

  

Move on to Step 3
 

3

  

If faults are found, restore the wiring between the engine control unit and the downstream temperature sensor

   See E5070 PARTICLE FILTER SYSTEM - DESCRIPTION

Replace the wiring if necessary

The test can be considered over

  

Replace the engine management control unit

   Op. 1060G80 DIESEL ELECTRONIC INJECTION CONTROL UNIT - R.R
 

4

  

Press the START/STOP button.

Check that the resistance across pin 1 and 2 of the sensor

   See K189 UPSTREAM PARTICULATE FILTER TEMPERATURE SENSOR (DPF)

is between 200 and 600 Ohms

  

Replace the temperature sensor

   Op. 1080B64 CATALYTIC CONVERTER EXCESS TEMPERATURE THERMOCOUPLE - R + R
 

5

  

Replace the engine management control unit

   Op. 1060G80 DIESEL ELECTRONIC INJECTION CONTROL UNIT - R.R
