Removing ( Refitting )

- Open the bonnet and support it appropriately.

1. Using a screwdriver, release the retaining springs from both ends of the telescopic strut (without removing them).

2. Remove the telescopic strut.

3. Undo the ball pins, if necessary.
Refitting ( Removing )

- Check that the telescopic strut is not damaged.

- If removed, retighten the ball pins.
