Structure of electrical/electronic system

The electrical equipment on this vehicle makes use of the F.L.Ore.N.C.E. structure developed specifically to integrate the most sophisticated electronic functions in the most efficient way.

This structure makes up the car''s "nervous system", directly controlling all the bodywork functions (access control, visibility, on board information, comfort, etc.) and communicates with the various chassis and power unit subsystems, improving system fault diagnosis, reliability, weight and cost.

A further advantage compared with traditional systems is the simplification of the fitting through the reduction in the number of control units (in line with the functions offered to the customer) and the number of power and signal connections, through the extensive use of serial communication networks (3 CAN dual wire networks, 1 LIN single wire network, 1 A-BUS single wire subnetwork).

Power distribution takes place by means of four fuse boxes and relay boxes, connected to the control elements (static actuators and relays). These control units also act as an interconnection for the wiring and as an electrical distributor to ensure the maximum level of electrical protection and the minimum degree of wiring complexity.

Network structure

The completed structure comprises three CAN communication networks connected by a gateway for transferring shared information:

- C-CAN (low speed: 500 kbit) for dynamic vehicle control

- B-CAN (high speed: 50 kbit) for managing bodywork functions

- CAN network for multimedia functions.

The gateway for communication between the C-CAN and B-CAN is located in the Body Computer.

The diagnosis of the nodes connected to the B-CAN network is carried out via the CAN, whilst the diagnosis for those connected to the C-CAN network is carried out by means of the specific K lines (5 ISO serial lines for diagnosis).

The K lines and the B-CAN network flow into the EOBD diagnostic connector centrally located on the Body Computer.

There are also the W line, ISO 5 serial for immobilizer recovery and the ISO 5 serial A-BUS line for the alarm, wiping, lighting, tyre pressure monitoring functions.

Replacing and initializing network nodes

Some of the CAN nodes are programmed with default settings which the customer will discover on acquiring the vehicle.

The nodes storing this information are the:

- Body Computer;

- Instrument Panel Node;

- Bluetooth Control Unit Node

- Radio Navigator Node;

- Climate Control Unit Node;

- Driver''s and Passenger Door Nodes ( HIGH version) or Front Door Node ( LOW version);

- Steering Lock Node.

If the Body Computer is being replaced, an "identical copy" of the Body Computer must be obtained from the Parts Dept as a V.O.R. order supplying the vehicle chassis number: this copy will contain all the default settings entered into the new vehicle which are stored in the Parts Dept. database for the vehicle chassis number.

If the Instrument Panel or the Climate Control System control unit are being replaced, the Parts Dept. will send a blank component: once fitted, the initial default data must be transferred to it by carrying out the PROXI ALIGNMENT procedure using the Examiner.

If one of the other nodes described above is being replaced, no initialization operation is required. However, always check that the system has not picked up errors during the removing-refitting operations, etc. using the Examiner.

Battery disconnection

If the battery is disconnected:

- Body Computer;

- Instrument Panel Node;

- Bluetooth Control Unit Node

- Radio Navigator Node;

- Climate Control Unit Node;

- Driver''s and Passenger Door Nodes ( HIGH version) or Front Door Node ( LOW version);

- Steering Lock Node.

All keep the information received and do not need to be initialized after the battery is disconnected, whilst the other nodes lose some or all of the information memorised.

Automatic battery disconnection device

The CBA includes an automatic battery disconnection device in series with the battery terminal capable of cutting off the starter/recharging lead power supply in an emergency.

This function is controlled by the inertia switch in the same way as for the fuel pump.

If the inertia switch is activated and the fuel cut off, the device must be "rearmed" by pressing the yellow button A.

BODY COMPUTER NODE (NBC)

The Body Computer Node (NBC), a component which manages many functions micro-electronically, is connected to the dashboard electro-mechanical control unit (CPL) and they are located in the area under the dashboard to the left of the steering wheel and make up a single unit known as the dashboard node (NPL).

Both the electronic and the electro-mechanical sections are also connected with the system and have fixed connectors for connection to the front, rear and dashboard wiring.

The fuses and relays are fitted on the electromechanical part whilst there is a fixed connector for the EOBD on the electronic section. This connector is used for fault diagnosis/programming via the K line for the NCM, NFR, NCR, CAB and fault diagnosis/programming via the B-CAN line for the components with this interface.

Logistic mode

Logistic mode: there is software inside the Body Computer that excludes all vehicle electrical loads, except the main functions (vehicle starting, lights). This function makes it possible to save battery energy which is useful when the vehicle is parked, possibly for long periods, in forecourts before being sold.

The function should be disabled in the workshop before the vehicle is handed over to the customer.

Deactivation procedure

The procedure is as follows:

- Connect the diagnostic device terminal to the vehicle EOBD socket and insert the TEG in the TEG Reader

- Check that the "alternator recharging" warning light is in flashing mode to indicate that the Logistic Mode low consumption mode is activated.

- Deactivate the low consumption supply mode by carrying out the fault diagnosis of the Body Computer using the Examiner.

- The Body Computer and all control units involved, on receiving the CAN message, will restore their full operation and send a confirmation message to the Body Computer node.

- Delete the error memory in all control units with a diagnosis function.

- Carry out a key OFF - key ON.

- Check that the "alternator recharging" warning light is on constantly.

INTEGRATED SYSTEM FOR REMOTE CONTROL UNITS

The integrated system for Homelink remote controls is a device that can be programmed to allow garage doors and gates to be opened remotely or to turn lighting and alarm systems on and off.

A single fixed control inside the vehicle, in the driver''s sun visor, can replace up to three portable remote controls carrying out the same functions as the individual remote controls it is replacing.

For example, to operate the door, simply press one of the three buttons instead of the portable remote control. The HomeLink warning light remains on whilst the signal is being transmitted.

The vehicle must be within range of the device that operates the service to be controlled. Work with the TEG inserted in TEG Reader

If necessary, the original portable remote control may always be used to operate the system.

The system may be set to the frequencies/codes of most portable remote controls marketed in Europe.

The HomeLink control panel and control unit are both housed in the sun visor.


Programming

The HomeLink may be programmed quickly by entering the frequencies/codes of three portable remote control units.

    Proceed as follows:

    • press external keys (A and C) and hold down;

    • led D will begin to flash after approximately 20 seconds;

    • release both keys.

    This initial operation deletes the standard codes preset in the factory and need not be repeated to programme the other keys.

    Continue to programme the first key:

    • press and hold the HomeLink key (A or B or C) to be programmed (do not release the key until the operation is complete);

    • when the HomeLink led D begins to flash slowly (after approximately 20 seconds, move the portable remote control as close as possible to the HomeLink (keeping the key to be programmed pressed down)

    The necessary gap between the original remote control and the HomeLink control unit depends on the system to be programmed

    • if the warning light flashes quickly, release both keys: this indicates that the signal has been correctly programmed;

    • if led D does not begin to flash quickly, retry by altering the gap between the HomeLink and the portable remote control (move it slightly further away). If the led continues to flash slowly, repeat the operation, altering the distance slightly.

    If necessary, programmed the other two keys in a similar manner.

    Alternative codes

    If the HomeLink system set as indicated above does not operate, this may be due to the fact that the original portable remote control is equipped with an alternative code.

    Consult the system manual to check whether the system to be controlled comes with an alternate code or proceed as follows:

    • press the HomeLink key programed for that remote control and hold down;

    • if an alternative code system is present, the HomeLink warning light flashes quickly for a short time and then stays on for two seconds. This sequence is repeated for 20 seconds.

    If the HomeLink unit is programmed for an alternative code system, it must now be synchronised with this system at the end of programming before it can operate correctly.

    Alternative code synchronisation

    Proceed as follows:

    • locate the setting key on the upper part of the motor on the device to be controlled (key colour and position may vary depending on the manufacturer);

    • press the "setting" key on the upper part of the motor for the device to be controlled: this usually activates the "setting" warning light for this device;

    • press the HomeLink programmed key within 30 seconds and then release again;

    • press the HomeLink key a second time and release again to conclude the operation. (On some devices, the operation will probably have to be repeated a third time to end the setting).

    The garage door or gate motor should now be able to identify the signal transmitted by HomeLink and then the relevant key may be pressed to open or close it.

    Programming a single key

    Another system remotely controlled by a previously occupied HomeLink key may be programmed but the previous programming will be lost. Proceed as follows:

    • press and hold the HomeLink key (A or B or C) to be programmed (do not release the key until the operation is complete);

    • when the HomeLink led D begins to flash slowly (after approximately 20 seconds, move the portable remote control as close as possible to the HomeLink (keeping the key to be programmed pressed down)

    The necessary gap between the original remote control and the HomeLink control unit depends on the system to be programmed

    • if the warning light flashes quickly, release both keys: this indicates that the signal has been correctly programmed;

    • if led D does not begin to flash quickly, retry by altering the gap between the HomeLink and the portable remote control (move it slightly further away). If the led continues to flash slowly, repeat the operation, altering the distance slightly.

    The system previously programmed on the HomeLink has now been deleted and the new system is ready to use.

    This operation does not have any repercussions on the other two HomeLink keys.

    Deleting programmed homelink keys

    To cancel the programming of all three keys, proceed as follows:

    • press external keys (A and C) and hold down;

    • led D will begin to flash after approximately 20 seconds;

    • release both keys.

    The operation is now complete.

    it is advisable to delete the HomeLink programming if the car is sold to a new owner.

    If you are unable to set up the HOMELINK unit successfully after following the above instructions, contact Aftersales Service (HOMELINK free hotline number 00800046635465) .

    The following information must, however, be recorded beforehand:

    • HOMELINK software version;

    • HOMELINK region code;

    • vehicle make and model, including year of manufacture and country of purchase;

    • make, model, age and frequency of use of the original portable remote control that the system needs to learn (if known).

    To identify the HOMELINK software version:

    • press key A or C (not both) and hold down for approximately 50 seconds;

    • led D stops flashing and then goes off;

    • continue holding the key down, the led will resume flashing after a few seconds;

    • the number of flashes corresponds to the software version number (for example: four flashes correspond to version 4.0).

    To identify the HOMELINK region code:

    • press key B and hold down for approximately 50 seconds until led D goes off;

    • Continue holding the key down, the led will resume flashing after a few seconds. The number of flashes indicates the region set by the manufacturer.

    For example:

    1 flash = rest of Europe,

    2 flashes = France,

    3 flashes = UK,

    4 flashes = Italy
