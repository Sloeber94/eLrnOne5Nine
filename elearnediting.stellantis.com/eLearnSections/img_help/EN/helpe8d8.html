3. CONSULTATION SCREEN

This chapter explains the commands you will find in the consultation screen.

 

 

 

Figure 4. Consultation screen

 

3.1. Vehicle parameters

In this area, for the model selected, you can define

  •   the engine type
  •   the manufacturing date range (if available)

Click on the name of the model above the two drop-down menus to return to the model selection page.

 

 

3.2. Sections menu

This menu lists the documentation available for the selected model, divided into sections.

The complete configuration includes:

 

 

3.2.1.  Consultation guide
  •   Technical Service Manuals
  •   Service News
  •   Active Campaigns
  •   TeSeO Newsletters
  •   TeSeO Technical Database

The "Consultation guide" is a document describing how the documents are structured, how to consult them
as well as general information.

 

 

3.2.2. Manual

The "Technical Service Manual" is further divided into the following sections:

  •   Technical specifications
  •   Descriptions
  •   Diagnoses
  •   Examiner Diagnoses
  •   Tests
  •   Procedures
  •   Electrical system

You need to select one of these items to begin your consultation: browsing will then proceed in the menus that
appear in the consultation area (see point 4).

 

3.2.3. Service News

This section contains the “Service News” for the model in question.

The 5 most recent Service News for that model are shown in the initial screen, before the contents divided into groups.

 

 

 

Figure 5. Service News Contents

 

 

3.2.4. Campaigns

This section contains all the documents related to service Campaigns for the selected model.

Select the desired subject.

A summary technical data sheet is then displayed, along with a button for you to download the document in .pdf format.

 

 

 

Figure 6. Campaigns

 

 

3.2.5. TeSeO Newsletters

The “TeSeO Newsletters” summarise the technical instructions related to specific product complaints, irrespective
of when the warranty expires.

 

They provide uniform technical and procedural guidelines for the Service Network and Customers, until the
official service solutions are published.

 

 

 

Figure 7. TeSeO Newsletters

 
3.2.6.  TeSeO Technical Database

The TeSeO Technical Database is an archive containing the solutions to complex cases solved by TeSeO using
structured and linear diagnosis methods.

 

 

 

Figure 8. Accessing the TeSeO Technical Database

 

 

 

 

 

Figure 9. TeSeO Technical Database

 

 

3.3.     Functions menu

This area contains a series of functions / commands for general use.

 

The functions of these commands are described below:

  •  Home: back to home page.
  •  eTECHplus: opens the search engine. Use this function to start a search for specific content
    inside sections of the Manual. Further information can be found in the "Help" menu of the application itself.

Figure 10. eTECHplus

  •   Print: prints the content displayed in the Consultation area. All documents can be printed.

N.B. Use this command to print the contents, and not the print command in your Explorer Browser.

  •  my e-mail: configures the e-mail address for resetting your password.
  •  Help: opens the help page, which is always available during browsing.
  •  Company data: opens the page that sums up the corporate data of Fiat Group Automobiles S.p.A.
  •  Logout: back to the login page.

5. BROWSING / CONSULTATION AIDS

In addition to normal browsing and consultation, a series of features were included which aim to aid users
in finding their way around the structure of the documents and enhance the display of content.

 

These additional features are:

  •  Navigation bar
  •  Backlink
  •  Electrical System Browsing
 
5.1. Navigation bar

 

Figure 14. Navigation bar and backlink

 

Figure 14 shows the "Navigation bar": the bar is automatically built up as you proceed in your browsing
of eLEARN so as to give users an idea of the path they have taken so far at all times.

 

Every browsing level is separated from the previous and next ones by the symbol ">".

 

The bar can be browsed in reverse too (towards hierarchically higher browsing levels) by clicking on the element indicating
the desired level.

 

The example illustrates the entire sequence followed in the navigation bar. You can get back to any level from
here.

 

 

5.2. Backlink

Often, to avoid duplicating content, the documents are linked to one another using links which are shown as underlined blue
text. The backlink was introduced to avoid "getting lost" during browsing.

 

Click on a link (as in Figure 14) to display the associated document: the corresponding link (backlink - Figure 14) is also displayed
at the beginning of the document to remind you which document you started browsing from.

 

Click here to return to the original document.

 

 

5.3. Electrical System Browsing

This section of the Manual has some specific features which the other sections lack: the methods of consultation are therefore
different. The aim is to give users the opportunity to consult the information onscreen, minimising the need to
print it out on paper.

 

For further details, please see the section entitled "Consultation Guide" which describes the interactive and 3D display functions
(if available).

 

 

 

Figure 15. Electrical System Display

 

5.3.1. Transversal browsing

The bar placed immediately above the image allows you to browse transversally among the different topics within the chosen wiring
diagram:

  •  Description
  •  Functional description
  •  Component location
  •  Wiring diagram

There is also a "Print electrical function" button which allows you to print all the topics of an individual electrical function
in a single command.

 

5.3.2. Image browsing control panel

This control panel allows you to browse within an image. The button functions are:

  •   "+" button: Enlarges the image
  •   "-" button: Minimises the image
  •   "=" button: Returns the image to its original dimensions
  •  Arrows: Allow you to move the image in all 4 directions

 

5.3.3. Enlarge image

Click on "Enlarge image" to open a second window (see Figure 16) to obtain an improved view
of the image.

 

 

 

Figure 16. Enlarged image

 

The window is entirely dedicated to displaying the image.

 

The "browsing control panel" described above can also be seen in this window.

 

On the right, there is also a list of codes for the components featured in the wiring diagram: run your mouse
over the code to display the long description of the code.

 

The print command is at the top, so that you can print the diagram on an entire A4 sheet of paper.

 

NOTE 1: to optimise the print-out, remember to set horizontal paper layout in the printer
properties.

 

NOTE 2: the content displayed on the screen is printed. To print the entire image, you always need to
return it to its original dimensions using the "=" button on the browsing control panel.

 

 

5.3.4. Table of components

The table beneath the "Wiring Diagram" and the "Component Location" includes a list of components featured in the
electrical function in question and allows you to browse through the individual electrical connectors and related removal/refitting procedures
for the corresponding components.

 

 

 

Figure 17. Table of components
