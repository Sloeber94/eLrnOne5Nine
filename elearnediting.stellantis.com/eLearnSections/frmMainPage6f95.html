Software and language update - Network Information and Service Manual Update


OPERATIONS IN NETWORK

The updates for the hands-free system with voice recognition and Bluetooth® in the Service Network can occur in the following cases.

1. Software update (SW):

-release, by FIAT, of a new SW version to improve the operation of the hands-free system with voice recognition and Bluetooth® or to correct problems reported by Customers;-replacement of the hands-free system with voice recognition and Bluetooth® (to update the component replaced at the last SW version available).

2. Update of existing language:

-release, by FIAT, of a new language version used by the hands-free system with voice recognition and Bluetooth®;-replacement of the hands-free system with voice recognition and Bluetooth® (to update the component replaced at the last language version available).

3. Loading a different language to the existing one:

-change of ownership of the vehicle to a country with a different language;-delivery of a new vehicle with a different language to the one spoken in the Market;-replacement of the hands-free system with voice recognition and Bluetooth® in a Market other than Italy (the parts arrive with Italian pre-installed).

If the hands-free system with voice recognition and Bluetooth® is being replaced, a different PROXI procedure to the standard one must be carried out.

Proxi procedure if the hands-free system with voice recognition and bluetooth® is being replaced

-Carry out the PROXI procedure using the Examiner after having entered the Make/Model/Version.-When the procedure is over, select "Control Unit Test" Marelli/Microsoft Convergence".-Select "Configuration" in the Active Diganosis ambient.-Select the command "Restart System Convergence".

How to update the device

Requirements

-Personal Computer with CD player and Windows© XP or Windows© 2000 operating system or Examiner Smart.-Latest version of CD for updating the hands-free system with voice recognition and Bluetooth®.-USBPen (minimum size 256 Mb) with manufacturer''s certification of compatibility with Windows© 2000 and Windows© XP Operating Systems.

Fiat periodically releases a CD with the software and language updates for the hands-free system with voice recognition and Bluetooth®. The CD includes a software application that allows the production of a USBPen (not supplied) with one of the following options:

-Updating of the operating system for the hands-free system with voice recognition and Bluetooth®.-Constrainment of the change/update to one language only in the hands-free system with voice recognition and Bluetooth® (irrespective of the language selected in the control panel).-Change/update of any language (including those supported by the hands-free system with voice recognition and Bluetooth®) starting from the one selected for the control panel.

Every CD cancels and replaces the previous one and contains all the updates for the operating system and the languages until that time.

The CD can be used on a normal PC (as long as it is equipped with a Windows© XP operating system) or on an Examiner Smart.

                          -the USBPen should be connected to an Examiner that is switched off or switching off from a previous work session-if the USBPen is removed during the current work session, e.g.: because it is used to transfer a language into the hands-free system with voice recognition and Bluetooth® so that the Examiner can recognize it and reuse it again, it must be reconnected to the equipment and rebooted.

                          Operations on the vehicle

                          If the updates have been downloaded successfully onto the USBPen, it can be extracted from the Examiner (or from the PC) and:

                          1. In the case of SW updating:

                          -insert the USBPen into the USB port for the hands-free system with voice recognition and Bluetooth® and turn the ignition ON-wait for the vehicle instrument display to show that the updating procedure has been launched-wait for the result of the update to appear on the vehicle instrument panel display.

                          If the result is positive:

                          -extract the USBPen from the hands-free system with voice recognition and Bluetooth®-check, through the Examiner control units Test, that the hands-free system with voice recognition and Bluetooth® has been updated with the SW release for the version required-check that the hands-free system with voice recognition and Bluetooth® does not have the faults indicated by the Customer-proceed with the language update (if present) repeating the procedure from the beginning.

                          If the outcome is negative ("NO language" indication):

                          -repeat the procedure from the beginning.

                          2. In the case of multilingual updating:

                          -turn the ignition key ON-insert the USBPen in the USB port for the hands-free system with voice recognition and Bluetooth®-on the instrument panel, select the language you wish to installe on the hands-free system with voice recognition and Bluetooth®-wait for the vehicle instrument display to show that the updating procedure has been launched-wait for the result of the update to appear on the vehicle instrument panel display.

                          If the result is positive:

                          -extract the USBPen from the hands-free system with voice recognition and Bluetooth®-check that the hands-free system with voice recognition and Bluetooth® has been correctly updated

                          If the outcome is negative ("NO language" indication):

                          -repeat the procedure from the beginning.

                          3. In the case of single language updating:

                          -insert the USBPen into the USB port for the hands-free system with voice recognition and Bluetooth® and turn the ignition ON-wait for the vehicle instrument display to show that the updating procedure has been launched-wait for the result of the update to appear on the vehicle instrument panel display.

                          If the result is positive:

                          -extract the USBPen from the hands-free system with voice recognition and Bluetooth®-check that the language for the hands-free system with voice recognition and Bluetooth® has been correctly updated.

                          If the outcome is negative ("NO language" indication):

                          -repeat the procedure from the beginning.

                          Solving problems on the vehicle

                          If the language is being update (either single or multilingual) the indication "No language" will appear on the instrument panel at the end of the procedure.

                          If this situation is repeated after having repeated the procedure from the beginning, this means that the USBPen being used is not compatible with the hands-free system with voice recognition and Bluetooth® and one of the USBPens in the USBPen Description chapter should be used.
