Cancels and replaces SN 55.10.08 of 20/06/2008 for information about INFO and S.O.S. services.

OPERATIONS IN NETWORK

We wish to remind you that if the Blue&Me™ Nav control unit is being replaced, to ensure the activation of the services activated previously by the customer, the following should be done:

-Order the new control unit through the E-Plus system following the instructions for the type of order known as "Blue&Me order entering" (see paragraph below).-When the component is received, the Parts packaging will contain a form (see examples in Fig. 5 and 6) to be used if the customer has subscribed to services (Info service, S.O.S., Insurance services, etc.), along with the control unit. For the reactivation of these services, complete the fields in the form marked with an asterisk (*) and fax the form to the number given (+39 06 41864814)-After fitting the new control unit, carry out the PROXI alignment procedure using the Examiner.-Also remind the customer to carry out the pairing operation for the telephones to be connected.-The services will be activated 7 working days after receipt of the fax. The customer will verify the activation of the services according to the procedures described in the Owner Handbook.

If you try and order a replacement Blue&Me™ Nav for a vehicle not fitted with this device, the system will reply with the following message "No NIP code associated with the Chassis Model specified!"

If it proves impossible to enable the services and/or order the control unit, refer to Service News 55.05.08
