General information

We hereby inform you that starting from 2012, initially for the Panda (319) model, and subsequently for the new models, there is no longer a Code Card (Fig. 1) on all models equipped with the CODE 2 system.

Fig. 1 – Code Card





The following specifies which models are equipped with the Code Card and for which models the electronic code can be requested through the CSPS system.

Cars initially supplied WITH Code Card

  • On all cars listed in the "Applicability" section EXCEPT Panda / Panda Van (model 319 / 519 with chassis number after 3078500), 500L / 500L Van, 500X, Tipo (356/357), Giulia, Stelvio, 4C, Fiat / Abarth 124 Spider, Fullback, Talento, Ducato FL (290/295 starting from chassis no. 02K02219) and Ypsilon (402), the Code Card is consigned together with the vehicle documents.
  • If necessary (e.g. if the Code Card is mislaid), the electronic code can be requested using the CSPS system (refer to the "Entering electronic/mechanical code request order" section below).
  • If the Customer wishes to purchase a Code Card, it can be requested using the CSPS system (refer to the "Entering Code Card purchase order" section below).

Cars initially supplied WITHOUT Code Card

  • The cars Panda / Panda Van (model 319/519 from chassis 3078500), 500L / 500L Van, 500X, Tipo (356/357), Giulia, Stelvio, 4C, Fiat / Abarth 124 Spider, Fullback, Talento, Ducato FL (290/295 starting from chassis no. 02K02219) and Ypsilon (402) do NOT have a Code Card.
  • To increase the security level of the 500X, Tipo (356/357), Giulia, Stelvio, Fiat / Abarth 124 Spider, Fullback and Talento, the electronic code is no longer supplied through the CSPS system, but it is calculated by the diagnosis tool (wiTechPlus – wiTech 2.0). If necessary (e.g. for coding a new key, Body Computer replacement, etc.), the diagnosis tool recognizes the vehicle data and automatically calculates the electronic code, which therefore does not need to be typed in.

The diagnosis tool must be kept connected to the vehicle and to Internet until the end of the procedure.
  • For Panda / Panda Van from chassis 3078500, 500L / 500L Van, 4C, Ducato from chassis no. 02K02219 and Ypsilon (402), the electronic code can be requested using the CSPS system, and Customers wishing to do so can purchase a Code Card (see points below).

ELECTRONIC CODE REQUEST THROUGH CSPS

The electronic code can be requested by CSPS for all the cars listed in the "Applicability" section EXCEPT 500X, Tipo (356/357), Giulia, Stelvio, Fiat / Abarth 124 Spider, Fullback and Talento.

Check on rightful ownership

To protect the Customer’s safety and that of the vehicles of the Group, if the electronic code is requested Dealers must establish the customer’s identity and ownership of the car, requesting the following:

  • an identification document proving ownership of the car (registration document or ownership certificate)
  • a valid identity document belonging to the customer

A copy of such documents must be filed progressively (with yearly numbering) and be kept available for any subsequent investigations for 5 years from the date of the order.
