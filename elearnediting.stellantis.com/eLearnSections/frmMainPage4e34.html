CUSTOMER'S REPORTED FAULT

The car does not start or shows marked power drops

TECHNICAL CAUSE

After the diagnosis, the low pressure pump has some faults

OPERATION

Implement the check list below.

If, after the diagnosis, the customer's claimed fault is due to the low pressure pump, do not perform any replacement and contact Te.Se.O.

Pressure measurement in the 3 points shown in the attached diagram

  

Start the engine, increase the rpm progressively and keep close to the max. rpm for about one minute.

  

Repeat pressure measurement for the 3 points shown in the diagram

  

Point 1) the pressure should range between 3.5 ÷ 5 bar*

  

If OK, low pressure problems can be excluded

  

If < 3.5 bar see point 2

  

The "diffuser" on the fuel supply unit bottom, Jet Pump (see picture) must be free from possible foreign bodies that could jeopardise its operation. Therefore, while removing the fuel supply unit, make sure that the tank and the unit tray are clean; while refitting pay attention so that no foreign bodies fall inside the tank!

It is strictly forbidden to tamper with and modify the fuel supply system
 

Point 2) Δp (p2-p1) must be < 0.8 bar

  

If OK see item 3

  

If KO replace the diesel filter
 

Point 3) the pressure should range between 0.3 ÷ 0.8 bar

  

If OK, low pressure problems can be excluded

  

If > 0.8 bar, check:

a) if there is a restriction on the return pipe
 

b) if there are chips/foreign bodies on the fuel supply unit bottom
 

If < 0.3 bar replace the fuel supply unit

* The pressure range is valid for the following engines:

1.6-1.9-2.0-2.4 JTD

1.3 (85/90 HP) JTD

Jtd cf4 engine: 1.3 (85-90 hp) - 1.6 - 1.9 - 2.0 - 2.4
