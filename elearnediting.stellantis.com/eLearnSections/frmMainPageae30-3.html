140 - Alfa 159   2.4 JTD 20V   THE TELEPHONE AUDIO CANNOT BE HEARD   N063   

With the telephone activated, whilst the speaker at the other end manages to hear the speaker in the vehicle, their voice cannot be heard in the vehicle.

This table does not consider faults due to service provider or phone function malfunction

The following telephones are enabled to operate with the Bluetooth® system and are supported by the system on the vehicle:

- Audiovox®: SMT 5600 (Orange™ C500)*

- Motorola®: V525*, V600*, Mpx220**

- Nokia®: 6230, 6600†, 6820, 7610*

- Sony Ericsson®: k700i, T610**, T637**, Z600**

* The system is not currently able to support a GPRS connection (General Packet Radio Services) when it is connected to this mobile phone.

** The system is not currently able to support a hands-free system when it is connected to this mobile phone.

† The system is not currently able to support call waiting when it is connected to this mobile phone.

RADIO VOLUME CHECK

  

All OK

  

Problems encountered

  

Operation
 

 

Check that the volume of the PHONE channel in the radio is not set to 0.

If it is, set it to a higher volume (e.g. 35) and check that the problem disappears.

  

End of diagnosis

  

The volume is already set to a high enough level

  

Move on to Step 2

ELECTRICAL CIRCUIT CHECK

  

All OK

  

Problems encountered

  

Operation
 

 

Check the continuity and the insulation of the electrical circuit between the radio and the speakers

 See E3510 RADIO

Also check that the radio connectors are not faulty

  

End of diagnosis
