- With the coolant cold, start the engine and move the speed selector twice from position "P" to position "D" and viceversa with the brake pedal depressed. Keep the selector in each position for 2 seconds.

- When the test temperature is reached, continue as described below leaving the gear lever in position "P" (it is advisable to use chocks to lock the wheels).

1. With the engine idling, remove the automatic transmission fluid level control plug (1a) and let the excess fluid drain through the drainage plug opening (1b).

Before removing the automatic transmission fluid level control plug, the engine should be idling because otherwise the transmission fluid will return to the sump raising the level beyond the upper limit of duct "a". In these circumstances the amount of oil necessary for the correct operation of the automatic transmission would be reduced.

When the automatic transmission fluid level control plug is removed, if the fluid level is below the upper limit of duct "a" only the amount of fluid collected in the latter will come out. This could give a false reading of the level and therefore the fluid should be topped up before the check.

- If the outcome of the test is positive, tighten the automatic transmission fluid level control plug complete with new gasket to the recommended torque.

- With the engine running and the brake pedal pressed, move the speed selector twice from position "P" to position "D" and viceversa keeping the selector in each position for 2 seconds.

- Set the selector to "P" and operate the parking brake (it is advisable to use chocks to lock the wheels).

- Clean any traces of oil from the area of the drainage port and tighten the automatic transmission fluid oil drain control plug to the recommended torque complete with new gasket.
