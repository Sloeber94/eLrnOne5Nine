140 - Alfa 159   2.4 JTD 20V   CRUISE CONTROL RECALL CONTROL NOT WORKING   D071   

After having deactivated the Cruise Control system by pressing the brake/clutch pedal, when the Cruise Control RECALL button is pressed the speed set previously is not restored
 

1

  

CHECK USING DIAGNOSTIC EQUIPMENT

  

ALL OK

  

PROBLEMS ENCOUNTERED

  

ACTION
 

 

Connect the diagnostic equipment to the engine management control unit and check that the lever RECALL position is recognized.

Check that the Cruise Control contacts are working properly in the RECALL position

 See Test 5580AC Cruise Control "RECALL" control check

  

Move on to Step 2

  

1. No continuity for lever contacts

  

1. Replace the Cruise Control lever assembly

 Op. 5580A10 CRUISE CONTROL LEVER ASSEMBLY - R+R
 

2. Power supply to lever interrupted

  

2. Move on to Step 2
 

2

  

ENGINE MANAGEMENT CONTROL UNIT CONNECTIONS CHECK

  

ALL OK

  

PROBLEMS ENCOUNTERED

  

ACTION
 

 

With the ignition key in the ON position and the Cruise Control in the ON position, check that there is a voltage signal from the Cruise Control to the engine management control unit when the RECALL button is pressed:

 See E5060 CRUISE CONTROL

  

Move on to Step 3

  

No voltage detected due to broken wiring

  

Repair the connections:

 See E5060 CRUISE CONTROL
 

3

  

CHECK ON CORRECT OPERATION

  

ALL OK

  

PROBLEMS ENCOUNTERED

  

ACTION
 

 

Check that the fault is no longer present by carrying out

 See Test 5580AE CRUISE CONTROL OPERATION ROAD TEST

  

End of diagnosis

  

The fault persists: engine management control unit defective

  

Replace the engine management control unit

 Op. 1056B82 INJECTION/IGNITION SYSTEM E.C.U. (ONE) - R + R
