5570 1 461 AC BLUE & ME™ SYSTEM (C1)
Failed operation / milometer flashing - Service Solution


FAULT COMPLAINED OF

The customer complains of one or both of the following problems:

- milometer flashing;

- Blue & Me system operation stuck:

TECHNICAL CAUSE

Loss of data alignment between Blue & Me control unit and Body Computer.

OPERATIONS IN PRODUCTION

Adoption of new control units with updated software (release 71.28).

OPERATIONS IN NETWORK

Network behaviour standards towards the Customer

-When this problem is reported and confirmed, reassure the Customer that it can be solved by reprogramming the Blue & Me system control unit.-After the operation show the Customer what has been done and make sure they are satisfied.

Service Solution

If this problem is reported, check the control unit software version and, if necessary, proceed with the update as described in the Operating Cycle below.

OPERATION CYCLE

Check whether updating is necessary

Check whether the software needs updating as follows:

- Connect using the EXAMINER and, in the Control Unit Test ambient, select the item Comfort in the Group menu (1 - Fig. 1) and then the item Marelli/Microsoft Convergence in the System menu (2 - Fig. 1).

Fig. 1



    - Check the control unit software version (1 - Fig. 2).

    Fig. 2



      If the control unit software is one of the following 4 versions:

      6135 - 6151 - 6278 - 6314.

      Continue with the updating.

      If the Software is NOT one of the above versions, there is no need to continue with the update.

      Equipment required for control unit software updating

      Before proceeding with updating the software, check that the following equipment is available:

      - Personal Computer with Windows© 2000 / Windows© XP / Windows© VISTA.

      - Internet connection to website.

      - USB Pen with manufacturer''s certification of compatibility with Windows© 2000 / Windows© XP / Windows© VISTA operating systems.

      Software updating procedure

      - To update the 6135 software version connect to the website:

         Aggiornamento C1V2 6135 pw blue.zip

      Download the C1V2_6135 pw blue.zip update file saving it in a folder on the PC.

      - To update the 6151 software version connect to the website:

         Aggiornamento C1V2 6151 pw blue.zip

      Download the C1V2_6151 pw blue.zip update file saving it in a folder on the PC.

      - To update the 6278 software version connect to the website:

         Aggiornamento C1V2 6278 pw blue.zip

      Download the C1V2_6278 pw blue.zip update file saving it in a folder on the PC.

      - To update the 6314 software version connect to the website:

         Aggiornamento C1V2 6314 pw blue.zip

      Download the C1V2_6314 pw blue.zip update file saving it in a folder on the PC.
