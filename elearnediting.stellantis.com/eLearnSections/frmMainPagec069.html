5520 1 141 RA DOORS NOT UNLOCKED USING REMOTE CONTROL
Cold start operation - Service solution


FAULT COMPLAINED OF

It is difficult or impossible to open the doors by means of remote control at low temperatures.

TECHNICAL CAUSE

Electronic key, T.E.G. (Transmitter for Entry and Go), door opening remote control with flat battery and/or anomalous operation.

Faulty ignition switch - T.E.G. Reader mode (NTR).

OPERATIONS IN PRODUCTION

Adoption of a new and improved T.E.G. Reader node (NTR).

OPERATIONS IN NETWORK

Network behaviour standards towards the Customer

-After having ascertained presence of the fault, reassure the customer that the problem will be solved by carefully diagnosing the problem and by replacing any faulty components.-After the intervention, check the work done and check that customer is satisfied.

Service Solution

If the complaint is present, diagnose the door opening/closing system with remote control and replace the faulty components, if needed, as described in the following cycle.

OPERATION CYCLE

For correctly running the cycle, close the vehicle doors using the remote control and wait for three minutes (the CAN must go to Sleep mode and the NTR LEDs must go out) before proceeding as follows.

    The remote control is powered by a CR2032 lithium battery (3 V, 220 mAh). Operation is guaranteed from 2.6 to 3.6 V and with a maximum current of 15 mA.

    At least 9000 activations lasting 1 s and 3000 activations lasting 5 s are guaranteed for three years.

    The battery voltage is monitored to check the charge level: the threshold is fixed at 2.6 ± 0.06 V; furthermore, 100 operations are possible after the remote control detects flat battery conditions.

    Remember to restore the variable code synch of the remote control after replacing the battery: press the remote control button twice to do this

    After the remote control has been operated for more than 255 times, the rolling code of the transmitter and of the receiver will no longer be synchronised (i.e. the receiver cannot identify the rolling code correctly). Restore synch by pressing the remote control button twice.
