OPERATIONS AT THE DEALERSHIPS

We inform you that on the web page www.blueandme.net you can find the software versions 5.5 and 5.6 to update the Blue&Me and Blue&Me Nav systems on cars coming from a less recent production, equipped with Convergence control unit.

The updates for software 5.5 and 5.6 do not apply to the cars with Lauberhorn control units. If the instrument panel display shows SET USB or USB MEDIA SETTING in the item MEDIAPLAYER of the Blue&Me menu, the car has a Lauberhorn control unit.

The new software versions 5.5 and 5.6 can:

  • increase compatibility with the most recent mobiles
  • listen to music recorded on iPod or iPhone

to listen to the music recorded on iPod or iPhone inside the car, the Lineaccessori catalogue contains a dedicated adapter to make these devices fully compatible with Blue&Me and Blue&Me Nav systems, along with the version 5.5 and 5.6 update.

Connecting to the page www.blueandme.net, in the section SUPPORT - DOWNLOAD, a free download for software versions 5.5 and 5.6 and the relevant instructions for the updating is available.

For all details about the installation procedure, carefully read the instructions that are attached and can be downloaded at the bottom of this SN, for your prompt reference.

WARNINGS

  • The updating process is simple and fast, because Blue&Me and Blue&Me Nav systems can be easily updated via USB. Nevertheless, the instructions must be carefully complied with, otherwise if the update is made in a wrong way, the system might not work anymore.
  • Remember that once this update has been performed, the previous software version cannot be restored anymore.
  • If Blue&Me works properly with phones paired and there is no need to listen to music files from IPod or iPhone devices (through the Mediaplayer adapter), it is not recommended to perform the software update.
  • After the software update, the Blue&Me Nav system loses the list of the latest destinations and the navigation settings
  • The update 5.6 can be installed only after installing the previous version 5.5; the two updates must be sequential, using the USB memory stick with the correct configuration according to the relevant instructions each time. DO NOT copy at the same time both updates on the same USB memory stick.
