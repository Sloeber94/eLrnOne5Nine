5580 2 061 RA RADIONAVIGATOR - BOSE SYSTEMS
Whistles and/or hissing – Service Solution


FAULT COMPLAINED OF

Whistles and/or hissing from the subwoofer and, sometimes, from the midrange speakers on the doors.

TECHNICAL CAUSE

The simultaneous presence of Radionavigator and of the BOSE audio system can cause the claimed fault, even if only in some circumstances.

OPERATIONS IN PRODUCTION

Adoption of new radionavigators.

OPERATIONS IN NETWORK

Network behaviour standards towards the Customer

  • Once the customer's claimed fault is confirmed, reassure the Customer that the fault will be solved by replacing the Radionavigator.
  • After the operation, show the Customer what has been done and make sure he is satisfied.

Service Solution

If the customer's claimed fault is confirmed, identify the Radionavigator manufacturing date: if it is before the above one, replace the Radionavigator according to Operating Cycle below.

OPERATION CYCLE

Find the Radionavigator code and read the production date following the procedures below.

If the date is before the below one:

  • 15 September 2011 for Radionavigators with TMC PRO function
  • 20 September 2011 for Radionavigators without TMC PRO function

replace the Radionavigator with a new one from the Spare Parts Dpt. as shown in Op. 5580M02 of the Service Manual.

PRODUCTION DATE CODING

The last 3 digits of the Device Code correspond to the day, month and year of production of the radionavigator.

The following tables show the coding between number/letter displayed and corresponding day, month and year.

In the example of Fig. 4, the code 77k corresponds to 07/07/2010.

The code F9L corresponds to 15/09/2011 while the code K9L corresponds to 20/09/2011 (last production days of potentially faulty Radionavigators with TMC PRO and without TMC PRO function respectively).
