FAULT COMPLAINED OF

Irregular operation/poor engine efficiency with presumed flow meter or EGR valve fault.

Irregular operation or irregular idling or a great deal of fumes (versions without DPF).

OPERATIONS IN NETWORK

In all cases where the malfunction of the flow meter or the EGR valve is suspected, before carrying out any type of replace and/or replacement operation, the diagnostic procedure described below must be carried out.

The diagnosis should be entered in SIGI under code 10601321RA

The time allowance for the operation is 0.30 hundreths of an hour.

Flow meter and egr valve fault diagnosis

Test conditions

For the results of the fault diagnosis to be meaninful and valid, the following test conditions should be observed:

-Ambient temperature above 18°C (figures read from the air temperature sensor on the flow meter);-Measurement altitude between sea level and a height of 1000 m;-For the check with the EGR open, the following errors should not be present P0045 - P0069 - P0100 - P0101 - P010F - P0111 - P0235 - P0401 - P0402 - P0403 - P060B - P0651 - P2004 - P2008 - P2009 - P2010 - P2011 - P2012 - P2013 - P2108 - P2112 - P2226 - P2620, because the engine management control unit intervenes with the recovery strategy on the operation of the EGR making the EGR valve opening value < 5% (closed position) until the error is validated (from present to intermittent).-Error P1206 should not be present on versions with DPF

for measurements made at altitudes above 1000 m and with the flow meter air temperature below 18°C, the measurement with the engine idling and the EGR valve open is no longer valid as a result of a correction in the control unit that is activated for these values and changes the management of the EGR.

Control procedure

a) Connect the Examiner preparing for the reading and measurement of the following parameters (the measurement ranges are shown at the side):

-Engine rpm-Measured air mass (correct values listed in Table 1)-Target air mass (value calculated by the control unit)-Engine coolant temperature (>= 90°C)-EGR valve opening (correct values listed in Table 1)-Accelerator position (minimum = 0%; max no load = 100%)

Values different from the recommended figures (for example pedal position 5% when idling) adversely affect the result of the measurement

b) Start the engine wait for the engine coolant temperature to reach >=90 °C (read from the Examiner);

c) With the engine running, having reached a temperature of >=90 °C with no loads applied (cooling fan, air conditioner, lights, etc.) measure the measured air mass in the following conditions:

-engine idling with EGR valve closed (EGR Valve opening = <5%)-with the engine idling, the EGR valve open* (EGR valve opening = 30% - 55%)

Record and print out the parameters for point a) for each of the 2 conditions using the Examiner.

(*) To go from the EGR valve closed to the EGR valve open condition, press the accelerator pedal gently and release it to return to idling (the EGR valve open state will last for around 70 seconds after which it will return to the EGR valve closed condition if the accelerator pedal is not pressed again).

d) Check the air mass values measured in the various conditions and compare them with the correct ones in Table 1 then, depending on whether they are within the tolerance range or higher or lower, carry out the operations recommended in Table 2.

Egr valve hysteresis fault diagnosis

After having carried out the above tests, in water, air and altitude conditions similar to those described previously, if the same values are obtained using the Examiner, proceed with the fault diagnosis of the hysteresis of the EGR valve as follows:

-Wait for the EGR valve to close (engine idling for 70 secs.).-Let the engine reach 2000 rpm, constant with no load.-Wait for 3 seconds.-Read the EGR valve opening value continuously for 15 seconds; memorize the minimum and the maximum readings.-Return to idling and go straight to 2000 rpm, repeating the reading procedure.-Check how much this figure varies. For example: maximum reading 48%, minimum 46% is a variation of 2%; maximum 45%, minimum 35% is a variation of 10%. The average value measured is not important, but the range of the fluctuation.-If in even only one of the 2 tests the fluctuation for the EGR valve is more than 5%, then the valve must be replaced. Otherwise, the valve hysteresis is considered normal.-Switch off the engine and disconnect the Examiner.

General notes

It should be remembered that the flow meter is a vital component for the operation of the engine; the following maintenance rules should therefore be followed to ensure its durability:

-The flow meter is not a component subject to periodic replacement (like, for example, the oil or air filters) therefore it should NEVER be replaced as a precaution but only if it is not working or damaged.-If there is a malfunction in the flow meter, it should NOT be cleaned inside using compressed air or detergent liquids because this would cause damage, but it should be replaced with a new one.-The cleaning operation can only be carried out inside the air filter casing during the maintenance/replacement of the filter cartridge.-Every time the air filter is replaced, before fitting the new filter element, it is advisable to remove any particles of impurities from the filter casing (by suction) as if they fall they could pollute or damage the flow meter sensitive element.-If the flow meter is believed to be defective, it should NOT be repaired or recalibrated in any way. Therefore any operation inside the flow meter to try and restore it to how it was originally or within the tolerance range is pointless.
