- Check the electrical connection.

- Place the control unit in position and attach the inner and outer retainers.

The control unit must be connected electrically at least 5 minutes before the key on.

Some of the CAN nodes, including the Bluetooth control unit, are programmed with default settings that the customer will find when they purchase the vehicle. If the control unit is being replaced, the Parts Dept. will send a pristine component: once fitted, the data memorized in the Body Computer must be transferred to it by carrying out the PROXY ALIGNMENT procedure using the Examiner.

- Once a new control unit is installed it is necessary to:

update the software;

check and, if necessary, set the voice message language correctly;

carry out the pairing operation for the telephones to be connected.
